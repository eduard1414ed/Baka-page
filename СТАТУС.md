## Где что лежит

- Посты — `src/content/posts/*.md` (143 выпуска + заметки; выпуск это пост
  категории `podcast`, связан с RSS полем `audioGuid`).
- Справочник тайтлов — `src/content/anime/*.json`, обложки `public/anime/`.
- Расшифровки — `src/content/transcripts/<guid>.json`, файл называется по guid.
- Сценарии эссе — `scripts/essay/*.md` (34 файла архива + новые из админки).
- Пословные данные новых выпусков — `transcripts/words/*.gz`;
  **у выпусков архива они только на сервере**, в `/root/baki-transcripts/output/`.
- Обложки выпусков — `public/episodes/`, список скачанного — `src/data/episodeCovers.mjs`.
- Админка — `public/admin/index.html` (свои поля) и `public/admin/config.yml`.
- Схемы контента — `src/content.config.ts`.
- Скрипты — `scripts/` (`fetch-anime.mjs`, `sync-anime.mjs`, `sync-episodes.mjs`,
  `fetch-episode-covers.mjs`, `transcribe/`).
- Роботы — `.github/workflows/` (добор выпусков из RSS + расшифровка, сверка аниме).
- Воркеры — `cms-auth/` (вход в админку), `publish-cron/` (отложенная публикация).

## Что происходит само

- **Раз в сутки (6:00 UTC)** робот добирает новые выпуски из RSS черновиками,
  распознаёт их и подставляет текст сценария, если он загружен в поле «Сценарий».
  Заводит задачу на GitHub — она же уведомление на почту.
- **Раз в минуту** воркер `publish-cron` публикует посты, у которых наступило
  время в поле «Когда опубликовать».
- **При каждой сборке** пересчитываются упоминания тайтлов, минуты на страницах
  тайтлов, поисковый индекс Pagefind и сжимаются загруженные картинки.
- **После публикации поста** робот `sync-anime` добирает новые тайтлы по меткам.

## Цифры

- Файлов в сборке — **526 из 20 000** (лимит бесплатного плана Cloudflare),
  вес 37 МБ, самый тяжёлый файл 3 МБ при лимите 25 МБ. Запас огромный.
  Когда опубликуете весь архив — около 850 файлов, индекс поиска 5,3 МБ.
- Архив расшифрован целиком: **141 транскрипт, 83 ч звука, 24 900 реплик.**
  Не расшифрованы только `ep-1` (служебный опенинг) и `ep-23` (чужой трейлер).
- На сайте опубликовано 7–8 постов, остальные 140+ — черновики, публикуете сами.
- Диск на Hetzner: занято 3,4 ГБ из 40.

## Текущие хвосты

1. **Этап 6 доделан не весь.** Сделаны шаги 1–4 (поиск). Осталось: «О подкасте»
   (шаг 5), RSS сайта (6), превью для соцсетей (7) и весь блок SEO (8–11).
   **Канонический адрес** из пункта 11 нужен в первую очередь: `bakapodcast.com`
   и `www.bakapodcast.com` отдают одно и то же, и поисковик может счесть это
   двумя сайтами-дублями.
2. **Этап 7 (Telegram) и этап 8 (дизайн) не начаты.**
3. **Сверка названий по архиву** — `--recheck-names`, бесплатно, имеет смысл
   когда справочник тайтлов подрастёт. Прогон архива этого не ждёт.
4. **Всплывающее окно «подпишись» у бонусных постов** — сознательно отложено
   до этапа дизайна. Пока бонусный пост выглядит как обычный.
5. **Уведомление на почту о сбое сборки** — от него отказались (у Cloudflare
   нет подходящего пункта для Workers). Если понадобится — варианты в истории.
6. **GitHub предупреждает про Node 20** в `actions/checkout@v4`, `setup-node@v4`,
   `setup-python@v5`. Сейчас только предупреждение; сломается — поднять версии
   в обоих файлах `.github/workflows/`.

## Невылеченные болячки

- **Неполная раздача после деплоя.** Первые 1–2 минуты edge-серверы Cloudflare
  отдают вперемешку старое и новое: страница отвечает то 404, то 200, часть
  картинок не грузится, сайт выглядит битым. Основную причину (галочка
  кэширования предыдущих версий в настройках воркера) сняли, стало заметно реже,
  **но не факт, что пропало совсем.** Обычно устаканивается само за минуту.
  Если нет — `npm run build`, потом `npx wrangler deploy`: заливает собранную
  `dist/` напрямую и всегда приводит сайт в консистентное состояние.
  Побочный эффект: запланированный пост может выйти на минуту-другую позже
  обещанных трёх.
- **24 выпуска, у которых сама реплика длиннее 90 секунд** (худшая — 7,5 минуты).
  Они распознавались до починки нарезки, пословных данных у них нет, бесплатно
  не переразбить. Внутри такой реплики таймкода на сайте не появится. Лечится
  только повторным распознаванием — это деньги и отдельное решение заказчика.
- **Два выпуска с честно неопознанными спикерами** — «Anime Awards 2024»
  и «Кайдзю № 8»: второй женский голос почти той же высоты, что у Ксюши
  (разница 3–5 Гц). Показываются как «Спикер не определён», чинится вписыванием
  имени в поле «Имена спикеров» в админке.
- **Падежи в упоминаниях не ловятся** («Ходячего замка» вместо «Ходячий замок»).
  Лечится вручную — поле «Варианты написания» у тайтла, там же кнопки-подсказки
  с формами, реально найденными в архиве.
- **Поиск по куску названия до двоеточия может дать ложные упоминания.** Заведёте
  тайтл «Твоё имя: …» — и слова «твоё имя» в обычном разговоре станут
  упоминанием. Лечится правкой `titleRu` или исключением упоминания.
- **Узкий случай в исключениях упоминаний:** если в одной реплике окажется
  второе упоминание того же самого тайтла, снятая галочка может спрятать не то.
  Предупреждения при этом не будет. Раньше случай был шире, 8 августа сузили.
- **Сценарий к архивному выпуску через админку подложить нельзя** — пословных
  данных этих выпусков нет в репозитории, они на сервере. Робот скажет об этом
  строчкой в логе, ничего не сломав. Понадобится — переносятся одной командой
  из `transcripts/README.md`.
- **Если RSS недоступен в момент сборки**, из ленты пропадут длительности,
  а со страниц выпусков — плееры. Не поломка, следующая сборка всё вернёт.
  Случай не теоретический: при отладке фид один раз не ответил.
- **Плашки тайтлов под постом потяжелеют, когда справочник вырастет.** Каждая
  тянет обложку ~20 КБ; при сотне тайтлов выпуск может набрать полтора десятка
  плашек. Не горит (`loading="lazy"`, стоят в самом низу), но третий, мелкий
  размер обложки завести нельзя — `CLAUDE.md` разрешает два размера на картинку.
- **`baki-cms-auth` и `publish-cron` деплоить бездумно нельзя** — им нужна явная
  строка `"workers_dev": true`, иначе деплой убьёт вход в админку и ручной
  запуск будильника. Список `ALLOWED_DOMAINS` у `baki-cms-auth` правится только
  в панели Cloudflare.
- **Веб-консоль Hetzner не передаёт Shift для некоторых символов** (`_` → `-`,
  `~` → `` ` ``, `"` → `'`). Обходной путь записан в памяти, искать
  по «hetzner-ssh-console».

## Что ждёт проверки руками в браузере

По правилу «Как проверяем работу» в `CLAUDE.md` это за заказчиком.

- **Кнопка загрузки сценария в админке** — не щёлкана ни разу. Загрузка
  не-картинки через Sveltia это как раз то место, где она уже расходилась
  с документацией Decap. Если поведёт себя странно — заменим на текстовое окно.
- **Переименование спикеров и применение исправлений названий через форму** —
  механизм проверен на сборке, но через админку заказчик их пока не сохранял.
- **Узкий экран (телефон)** — карточки упоминаний, длинные названия, метка
  «1 ч 35 мин слушать», новая строка минут в карточке тайтла.
- **Транскрипты 36 выпусков со сценариями** — как выглядят на странице, работает
  ли по ним поиск, едет ли текст за плеером. Все 36 пока черновики.
- **Кнопка «Следить за плеером» на живом звуке**, плавность автопрокрутки, клик
  по минуте с реальным звуком (разрешит ли браузер звук сразу).
- **Первый бонусный пост**, когда заведёте: должен появиться в разделе «Подкаст»
  с плашкой «Бонус» и без метки времени.

Смотреть локально: `npm run build`, затем `npm run preview` — **адрес сервер
печатает сам** (4321 бывает занят прошлыми запусками, тогда возьмёт 4322;
открывать надо напечатанный, иначе смотрите старую версию сайта).
