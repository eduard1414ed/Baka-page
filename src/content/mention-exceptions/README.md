# Исключения упоминаний

Что убрать из упоминаний тайтлов руками (тз/05, шаг 5). Сейчас правится
только в файлах — поле в админке будет в следующей сессии, вместе
с переименованием спикеров.

Один файл на выпуск. **Имя файла — то же, что у расшифровки**
в `src/content/transcripts/` (guid выпуска из RSS). Файла нет — значит
из этого выпуска ничего не убрано, это нормальное состояние.

Схема проверяется при сборке — см. `src/content.config.ts`.
Логика — `src/lib/mentionExceptions.mjs`.

## Зачем это нужно

Названия ищутся по справочнику совпадением текста, а среди названий аниме
есть обычные слова («Монстр»). Такое ложное срабатывание надо уметь убрать —
так же, как тайтл убирается крестиком из поля «Тайтлы поста» в CMS.

## Пример

`src/content/mention-exceptions/7f1cee69-551d-4915-9b52-d6af624bd3da.json`

```json
{
  "episodeGuid": "7f1cee69-551d-4915-9b52-d6af624bd3da",
  "hiddenAnime": ["monster"],
  "hiddenMentions": [
    {
      "anime": "naruto",
      "replica": 42,
      "occurrence": 0,
      "text": "Наруто",
      "note": "речь о косплее, а не о тайтле"
    }
  ]
}
```

- `hiddenAnime` — тайтл убран из выпуска **целиком**, все его упоминания.
- `hiddenMentions` — убрано **одно** упоминание.

## Как найти номер реплики и вхождения

`replica` — место реплики в массиве `replicas` файла расшифровки, считая с нуля.
`occurrence` — какое это по счёту упоминание **этого же тайтла** внутри
**этой же реплики**, тоже с нуля. Если в реплике оно одно — `0`.

На собранной странице эти же числа стоят прямо на упоминании:
`data-replica` и `data-occurrence`.

## Почему номер реплики, а не таймкод

Впереди выравнивание готовых сценариев по звуку для 36 выпусков (шаг 2 тз/05).
После него **таймкоды сдвинутся**, и все привязки по времени рассыпались бы
разом. Номер реплики пересчёт времени переживает.

## Что будет, если привязка всё-таки потеряется

**Упоминание останется на странице.** Правило намеренное: лишнее в выдаче видно
и чинится, а тихо пропавшее не заметит никто. Сборка при этом пишет в лог
предупреждение с именем файла — так что молча в мусор исключение не превратится.

Привязка считается потерянной, если реплики с таким номером больше нет,
в ней нет такого вхождения, или `text` не совпал с тем, что там написано
(сверка без учёта регистра и без разницы между «е» и «ё»).
