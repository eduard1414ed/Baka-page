# ТЗ: тесты на сайте «Бака!»

Статус: черновик v1 · 2026-10-08
Это единственное место, где описана функция тестов. Промпты сессий ссылаются сюда, а не копируют правила.

---

## 1. Что делаем

Новый тип материала — **тест**. Его можно пройти на сайте, в конце будет результат, которым можно поделиться.

Два вида:
- **Викторина** — у каждого вопроса есть верный ответ. Итог зависит от числа верных.
- **Личностный тест** — верных ответов нет. Итог определяется баллами за выбранные варианты.

Статистику ответов («так же ответили 34%») **не делаем**. Сайт остаётся статичным, сервер для тестов не нужен.

---

## 2. Тест как материал сайта

- У теста своя страница. Адрес предварительно `/tests/<slug>/`, но его надо сверить с тем, как устроены адреса остальных материалов (это входит в разведку).
- На главной и в лентах тест выглядит **как остальные материалы**: та же карточка, та же логика сортировки по дате, метка типа «Тест».
- Страница теста использует **тот же макет, что и статья**: шапка, заголовок, подзаголовок, обложка, панель действий, подвал, блоки перелинковки. Отличается только тело: вместо текста статьи — вступление и вопросы.
- Тест попадает в поиск Pagefind как обычный материал.

---

## 3. Как тест заполняется в админке (Sveltia CMS)

Новая коллекция «Тесты». Поля:

**Общие**
- Заголовок, подзаголовок, дата, обложка, slug — как у статей.
- Вид: `викторина` / `личностный`.
- Вступление — обычный текст с форматированием.

**Вопросы** (список)
- Текст вопроса.
- Картинки: ни одной, одна или сетка до 4 (2×2, как на референсе).
- Варианты ответа (список, от 2 до 6), у каждого:
  - текст варианта;
  - *викторина:* галочка «верный» (ровно один на вопрос);
  - *личностный:* к каким результатам этот вариант добавляет балл (выбор из списка результатов этого теста, можно несколько);
  - *личностный, необязательно:* короткая реплика, которая появляется после выбора.
- *Викторина:* пояснение к вопросу. Показывается внутри карточки верного варианта после ответа, как на референсе. Ссылки внутри пояснения разрешены.

**Результаты** (список)
- id (латиницей, для адреса), заголовок, картинка, текст.
- *Викторина:* диапазон верных ответов «от … до …».
- Необязательно: ссылки на посты и тайтлы «Баки». Выводятся под результатом.

Если Sveltia не умеет прятать поля в зависимости от вида теста, оба набора полей показываются всегда, с подсказками «только для викторины» / «только для личностного».

### Проверка при сборке

Сборка **падает с понятным сообщением** (без молчаливых исправлений), если:
- в вопросе викторины не ровно один верный вариант;
- диапазоны результатов викторины не покрывают все значения от 0 до числа вопросов или пересекаются;
- вариант личностного теста ссылается на несуществующий результат;
- у личностного теста есть результат, который невозможно получить ни при каком наборе ответов;
- у результата нет id или id повторяются.

## 4. Как тест проходится

Все вопросы идут на одной странице подряд, как на референсе: «Вопрос 1 из 12», текст, картинки, варианты.

**Викторина**
- Клик по варианту фиксирует ответ, поменять его нельзя.
- Верный вариант подсвечивается зелёным с ✓, выбранный неверный — красным с ✗. Остальные остаются нейтральными.
- В карточке верного варианта раскрывается пояснение.
- Если выбран верный — то же самое, но без красного.

**Личностный тест**
- Клик фиксирует ответ, выбранный вариант выделяется (нейтральным акцентом, не зелёным).
- Если у варианта есть реплика, она раскрывается под ним.
- Подсчёт: каждый вариант добавляет по 1 баллу результатам, к которым привязан. Побеждает результат с наибольшей суммой.
- **Ничья:** побеждает тот, что выше в списке результатов. *(Решение по умолчанию — поправить, если нужно иначе.)*

**Финал (оба вида)**
- Когда отвечен последний вопрос, внизу появляется блок результата, и страница плавно прокручивается к нему.
- Викторина: «9 из 12» плюс результат диапазона.
- Блок: картинка, заголовок, текст, ссылки (если есть), кнопки шаринга (раздел 5), кнопка «Пройти ещё раз».
- Ответы не запоминаются: после перезагрузки тест начинается заново. *(По умолчанию.)*
- Без JavaScript страница показывает вопросы и варианты как текст, без интерактива. Это нужно для поисковиков.

### Требования дизайн-системы
- Варианты ответа — кнопки высотой не меньше 44 px, доступны с клавиатуры.
- Картинки в вопросах и результатах не обрезаются (`object-fit: contain`).
- Всё на существующих токенах, **кроме согласованного исключения**: цвета состояний «верно» и «неверно» (раздел 6).

## 5. Шаринг результата (обязательно)

- У каждого результата есть **своя страница**: `/tests/<slug>/<result-id>/`.
  Она собирается статично, в макете статьи: «Результат теста „…“», картинка, заголовок и текст результата, крупная кнопка «Пройти тест» на страницу теста.
- У каждой такой страницы **своя превью-картинка** (Open Graph, 1200×630). Она генерируется при сборке в стиле сайта: название теста, заголовок результата, картинка результата, логотип. Шрифты сайта.
  При пересылке ссылки в Telegram или VK видно именно ваш результат.
- Кнопки в блоке результата: Telegram, ВКонтакте, «Скопировать ссылку». На телефоне дополнительно системное «Поделиться».
- Текст при шаринге: «Мой результат в тесте „…“ — …».
- Викторина: в ссылку добавляется счёт (`?score=9`). Страница результата показывает «9 из 12» на экране, а превью — общее для диапазона (статичный сайт не может нарисовать превью под каждый счёт).
- Страницы результатов закрыты от индексации (`noindex`), канонический адрес — страница теста. Это нужно, чтобы поисковики не видели десятки почти пустых страниц. *(По умолчанию.)*

## 6. Исключение из дизайн-системы: цвета состояний

Разрешено добавить токены для двух состояний варианта: **верно** (зелёный) и **неверно** (красный). Для каждого — фон, рамка, текст, иконка.

- Оттенки подбираются под палитру сайта. Это не «стандартные» зелёный и красный, а приглушённые, тёплые или холодные — в зависимости от того, что сочетается с фоном и акцентом.
- Ed выбирает из 3–4 вариантов на странице сравнения.
- Текст на цветном фоне должен проходить контраст WCAG AA (4.5:1).
- Исключение записывается **один раз** в документ дизайн-системы с пометкой, что оно касается только тестов.

## 7. Этапы

| # | Сессия | Что получается |
|---|---|---|
| 1 | Разведка + палитра | Отчёт об устройстве сайта; страница сравнения цветов; Ed выбирает оттенок. Код сайта не меняется. |
| 2 | Схема + админка | Коллекция «Тесты» в Sveltia, проверки при сборке, один тестовый тест-черновик. |
| 3 | Викторина | Страница теста в макете статьи, карточка в лентах, прохождение викторины, блок результата. |
| 4 | Личностный тест | Подсчёт баллов, реплики, выделение выбора. |
| 5 | Шаринг | Страницы результатов, превью-картинки, кнопки. |

Каждая сессия заканчивается проверкой в браузере и обновлением CLAUDE.md и СТАТУС.md.

---

## 8. Решения по умолчанию, которые можно поменять

- Ничья в личностном тесте → побеждает результат выше в списке.
- Прогресс прохождения не сохраняется.
- Страницы результатов не индексируются.
- Все вопросы на одной странице, а не по одному.
