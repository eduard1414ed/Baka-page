# Этап 3. Тайтлы аниме

## Цель

Кликаю по названию аниме в тексте — попадаю на страницу со всеми упоминаниями.
Это главная фишка проекта.

## Задачи

1. Справочник тайтлов (`src/content/anime/*.json`) по модели из `CLAUDE.md`.
2. **Разметка в тексте.** В редакторе выделяю «Фрирен» → кнопка «Аниме» → поиск
   с подсказками из Shikimori → выбираю → в Markdown пишется `[Фрирен](anime:frieren)`.
   При сборке превращается в ссылку на `/anime/frieren`.
3. **Поле `anime` заполняется автоматически** из разметки в тексте. Руками
   добавляю только то, что упомянуто не в тексте (например, в подписи к картинке).
4. Ссылкой делать **только первое упоминание в посте**, дальше обычный текст.
5. **Проверка при сохранении:** скрипт ищет в тексте известные тайтлы без разметки
   и предлагает разметить — «упомянут „Стальной алхимик", отметить?».
6. Данные из Shikimori: обложка, год, студия, оригинальное название, описание.
   AniList — запасной источник, если в Shikimori не нашлось.
7. Страница `/anime/[slug]`: карточка тайтла + все посты с упоминанием.
8. Страница `/anime`: сетка обложек, сортировка по числу упоминаний.

## Приёмка

- Пишу пост, размечаю два тайтла, публикую — внизу поста появились их плашки.
- Кликаю по названию в тексте — попадаю на страницу тайтла с обложкой и списком постов.
- На `/anime` вижу сетку всех упомянутых тайтлов.
- Отключаю интернет у Shikimori (или он лежит) — сайт всё равно собирается.

## Подводные камни

- **Кэширование обязательно.** Данные тайтла запрашиваются один раз и сохраняются
  в JSON. При сборке API не дёргать — иначе каждая сборка будет медленной и хрупкой.
- **Обложки скачивать к себе** в `public/anime/`, не подгружать с чужого сервера.
- Shikimori требует заголовок `User-Agent` с названием приложения и ограничивает
  частоту запросов — при массовом импорте делать паузы между запросами.
- Тайтл идентифицируется по ID, не по названию. «Фрирен» и «Frieren» — один тайтл.
