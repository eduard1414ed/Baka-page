# Этап 8. Дизайн

## Цель

Сайт перестаёт выглядеть как черновик. К этому моменту всё уже работает —
меняем только внешний вид.

## Задачи

1. Я приношу 3–5 сайтов-референсов и говорю, что в них нравится.
2. Все правки — через файл дизайн-переменных с первого этапа. Если приходится
   лезть в компоненты и править цвета там, значит первый этап сделан неправильно;
   сначала вынести переменные, потом менять дизайн.
3. Типографика: шрифт с хорошей кириллицей, читаемый размер основного текста,
   комфортная ширина колонки.
4. Тёмная тема как основная: скриншоты и обложки аниме на тёмном фоне
   смотрятся как кадры, на светлом — как вырезки из журнала.
5. Сетка обложек на `/anime` — витрина сайта, ей уделить отдельное внимание.
6. Карточки постов разных категорий должны отличаться визуально.
7. Картинки для соцсетей: генерировать автоматически из заголовка и обложки.
8. Проверить скорость: сайт должен открываться быстро с телефона в мобильной сети.
9. Проверить доступность: контраст, размер кликабельных зон, работа с клавиатуры.

## Приёмка

- Открываю сайт с телефона и с компьютера — везде выглядит цельно.
- Меняю акцентный цвет в одном файле — меняется весь сайт.
- Страница открывается быстро даже на слабом интернете.

## Подводные камни

- Не переделывай логику под дизайн. Если для красивого решения нужно менять
  структуру данных — сначала скажи мне, обсудим отдельно.
