# Этап 1. Каркас и деплой

## Цель

Пустой, но настоящий сайт в интернете, который пересобирается сам при каждом
изменении. Без этого следующие этапы делать вслепую.

## Задачи

1. Создать проект на Astro в текущей папке.
2. Завести репозиторий на GitHub и сделать первый коммит.
3. Подключить Cloudflare Pages: автосборка при пуше в основную ветку.
4. Настроить сервис-посредник на Cloudflare Workers, чтобы админка на следующем
   этапе могла логинить меня через GitHub. Сделать это сейчас, один раз,
   и больше к нему не возвращаться.
5. Сделать общий шаблон страницы: шапка, подвал, место под контент.
6. Главная страница: название подкаста, описание, ссылки на площадки.
7. **Файл дизайн-переменных.** Цвета, шрифты, размеры, отступы, скругления —
   всё в одном месте, в CSS-переменных. Дальше по проекту использовать только их,
   не писать цвета и размеры прямо в компонентах. На восьмом этапе дизайн должен
   меняться правкой этого файла.
8. Тёмная тема по умолчанию.
9. Настроить обработку картинок так, чтобы каждая давала не больше двух файлов
   (см. «Ограничения хостинга» в `CLAUDE.md`).
10. Подключить домен, когда я его куплю (можно позже, сайт работает и без него).

## Приёмка

- Открываю ссылку с телефона — вижу название подкаста и ссылки на площадки.
- Меняю строчку текста через админку GitHub → через минуту вижу изменение на сайте.
- Сайт открывается быстро, не мигает белым.

## Что нужно от меня

- Аккаунт GitHub, аккаунт Cloudflare (оба бесплатные)
- Название и описание подкаста, ссылки на все площадки
- Логотип, если есть

## Подводные камни

- Не подключай пока никаких API, CMS и внешних сервисов. Только каркас
  и посредник для логина.
- Не ставь тяжёлых зависимостей: чем меньше на старте, тем легче чинить дальше.
- Перед настройкой сверься с актуальными лимитами Cloudflare на их сайте —
  они меняются по нескольку раз в год.
