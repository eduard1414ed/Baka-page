# Этап 4. Выпуски и плеер

## Цель

Весь архив подкаста на сайте, со слушалкой, и новые выпуски появляются сами.

## Задачи

1. Разбор RSS подкаста при сборке: номер, дата, длительность, ссылка на аудио, GUID.
2. Выпуск = пост категории `podcast`, связанный с RSS через поле `audioGuid`.
3. **Робот сверки:** появился выпуск в RSS без поста — создаёт черновик
   категории `podcast` с заполненными техническими полями. Я дописываю текст
   и размечаю тайтлы. Уже опубликованные посты не трогать никогда.
4. Аудиоплеер: закреплён внизу экрана, не прерывается при переходе между
   страницами, помнит позицию.
5. Страница выпуска: плеер, шоуноты, кнопки площадок, упомянутые тайтлы.
6. Лента выпусков с фильтрами по категории.
7. **Блок таймкода** в редакторе: пишу `12:34` — получается ссылка,
   перематывающая плеер на это место.
8. Свои видеофайлы раздаются с моего сервера Hetzner, не из репозитория.

## Приёмка

- Открываю страницу выпуска, жму play, перехожу на другую страницу — звук не прервался.
- Кликаю по таймкоду в шоунотах — плеер перематывается.
- Публикую новый выпуск в хостинге подкаста — назавтра в админке лежит черновик.

## Подводные камни

- Аудио отдаёт хостинг подкаста по ссылке из RSS. **Не копировать файлы к себе** —
  иначе развалится статистика прослушиваний.
- Плеер не должен перезапускаться при переходе между страницами. Это самая
  частая ошибка в таких сайтах — проверь отдельно.
- RSS может отдавать битые или неполные данные. Сборка не должна из-за этого падать.
