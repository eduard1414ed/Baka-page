# Фавикон «Бака!» — ば

Знак: хирагана ば, набрана Noto Serif CJK JP Black и переведена в кривые.
Дакутэн (゛) — знаком озвончения, красный `#D8452F`.
Плашка `#F1EEF0`, штрих `#14110F`.

## Файлы

| Файл | Куда |
|---|---|
| `favicon.svg` | основной, в корень сайта. Светлая плашка по умолчанию, выворотка через `prefers-color-scheme: dark` |
| `favicon.ico` | в корень, для старых браузеров. Внутри 16/32/48/64 |
| `apple-touch-icon.png` | 180×180, в корень. Без скруглений — iOS накладывает свою маску |
| `favicon-16/32/48/96.png` | запасные растровые размеры |
| `favicon-192.png`, `favicon-512.png` | для веб-манифеста и установки на домашний экран |
| `ba-mark.svg` | знак без плашки, прозрачный фон — для шапки, писем, презентаций |
| `ba-mark-mono.svg` | одноцветный, наследует `currentColor` — для мест, где нужен один тон |

## Разметка

Положите файлы в корень и вставьте в `<head>`:

```html
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
```

Порядок важен: `.ico` идёт первым как запасной вариант, браузеры с поддержкой SVG
возьмут второй `link`. У Astro положите файлы в `public/`, а разметку —
в общий layout.

## site.webmanifest

```json
{
  "name": "Бака! — подкаст об аниме",
  "short_name": "Бака!",
  "icons": [
    { "src": "/favicon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/favicon-512.png", "sizes": "512x512", "type": "image/png" }
  ],
  "theme_color": "#F1EEF0",
  "background_color": "#F1EEF0",
  "display": "standalone"
}
```

## Кэш

Браузеры держат фавиконы долго. После выкладки откройте `https://ru.bakapodcast.com/favicon.svg`
напрямую и обновите с очисткой кэша, иначе старая «Б» будет висеть ещё несколько дней.
На проде помогает вечное `Cache-Control` с версией в имени файла, но для фавикона проще
один раз пережить.

## Если поменяете гарнитуру

Знак собран на Noto Serif CJK JP Black. Если хирагана в логотипе набрана другим шрифтом —
пришлите файл, пересоберу на нём, чтобы фавикон и ばか в шапке были из одной семьи.
