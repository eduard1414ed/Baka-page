# Сборник «Обзор всех аниме осени 2022»

Чем собран пост `obzor-vseh-anime-oseni-2022` из одиннадцати постов канала —
задача 18, [разбор](../../статус/задача-18-sbornik-oseni.md).

## Чем это отличается от `scripts/dtf/`

Тем же, чем осенний марафон отличается от зимнего и летнего: **статьи на DTF
у него нет вовсе.** Зимний сборник склеен из пяти статей DTF, летний — из одной;
осенний выходил только в телеграме, по посту на сериал.

Отсюда всё остальное:

- **первоисточник — сами посты сайта**, привезённые импортом из канала,
  и берутся они из git по закреплённому коммиту (`SOURCE_COMMIT` в `build.mjs`);
- **сверять не с кем, кроме них**: чужого сервера, который отдал бы тот же
  текст, не существует;
- **сами одиннадцать постов снесены** как дубли — решение заказчика, то же,
  что с летними и зимними кусками. Поэтому коммит и закреплён: ветка уедет
  вперёд, а он останется, и пересборка через год возьмёт ровно тот же текст.

Общее с DTF-переносами берётся оттуда, а не переписывается: `postPath`,
заслон `writeGuarded`, `shortStudio`.

## Как пользоваться

```
node scripts/osen-2022/verify.mjs             # сверить пост с постами канала
node scripts/osen-2022/verify.mjs --selftest  # спросить проверки подлогами
node scripts/osen-2022/build.mjs              # пересобрать пост
node scripts/osen-2022/images.mjs --from=<папка>   # пережать кадры заново
```

**Перед пересборкой попросите заказчика закрыть админку.** Открытая вкладка
держит свою копию поста и при сохранении пишет её поверх целиком.

**Сборщик берёт шапку и метки `::anime-ref` из живого файла**, а не сочиняет
заново, и отказывается писать, если пост правили руками (`guard.mjs`).

## Что тут лежит

| Файл | Что делает |
|---|---|
| `build.mjs` | склейка одиннадцати постов в сборник; шапка, порядок, подписи |
| `images.mjs` | кадры заказчика → сжатые копии в `public/images/uploads/`; **и раскладка «какой кадр какому тайтлу»** |
| `verify.mjs` | сверка знак в знак, раскладка, порядок, подводка; `--selftest` |

**`images.mjs` — единственное место, где живёт связь «файл → тайтл».** Имена
у оригиналов случайные (`bb5a8413…jpg`), опознан каждый кадр глазами. Подпись
не от того тайтла хуже пропавшей: она выглядит правильной, и заметить её будет
некому.

## Чего тут нет

Оригиналов картинок — правило проекта. В посте лежат сжатые копии (webp,
качество 85, вписать в 2048 — то же правило, которым сжимает админка).

## Подводку написал не заказчик

У зимнего, весеннего и летнего марафонов вступление авторское — оно было
в статье на DTF. У осеннего его нет ни одного: в канале марафон шёл россыпью.
Текст в `INTRO` (`build.mjs`) написан по образцу трёх соседних сборников
по прямой просьбе заказчика, и это сказано вслух здесь и в разборе задачи.
