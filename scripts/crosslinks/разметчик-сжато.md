# Разметчик — сжатая инструкция (для помощников)

Сжатая версия `разметчик.md` (сессия 1в): те же правила без пояснений для
людей, два примера вместо четырёх. **Словарь меток и известные люди — в начале
файла пачки** (собирается из `статус/перелинковка/словарь.md`); сам словарь
читать не нужно. Меняете правило — меняйте в обеих версиях.

## Задача

Ты размечаешь посты сайта подкаста об аниме. По карточкам скрипт найдёт пары
постов для ссылки «наш материал на ту же тему», причину из карточки прочтёт
человек. **Лучше пусто, чем натянуто**: лишняя метка даёт ссылку, которую
отклонят; пропущенная теряет одну.

Вход — пачка постов: заголовок, вид, дата, тайтлы, найденные счётчиком (id, число
упоминаний, роль по счётчику — он считает слова и смысла не понимает), текст
блоками `[n]` (номера с пропусками — так надо), иногда вопросы фильтра `Ф1…`.
У выпусков, бонусов и видеоэссе текст — только описание; не додумывай
содержание записи. **У видеоэссе бывает «выжимка расшифровки»** — размечай по
описанию и выжимке вместе, номера блоков бери из описания (если тема только
в выжимке — укажи первый блок описания).

## Выход

**Только JSON-массив** карточек, по одной на пост, в порядке пачки, в файл,
который тебе назвали. Все поля обязательны, пустые списки — `[]`.

```json
{
  "id": "id поста",
  "about": "О чём пост — одна фраза, 8–20 слов, суть, а не пересказ",
  "labels": [{ "code": "код", "level": "главная | раздел | мимоходом", "blocks": [3] }],
  "people": [{ "name": "Имя Фамилия", "role": "мангака", "level": "главный | упомянут", "blocks": [2] }],
  "studios": [{ "name": "MAPPA", "level": "главная | упомянута", "blocks": [1] }],
  "subjectAnime": [{ "anime": "id", "why": "почему пост о нём" }],
  "coverage": [{ "anime": "id", "scope": "общий | узкий", "aspect": "что именно (для узкого)", "why": "фраза" }],
  "filter": [{ "q": "Ф1", "verdict": "тема | пример", "why": "фраза" }]
}
```

**labels.** Коды только из словаря, дословно.
- `главная` — пост ОБ ЭТОМ: тема в заголовке, или ей отдан весь текст или
  больше половины. `раздел` — тема одного раздела подборки или одного большого
  блока. `мимоходом` — названа явно, но пост о другом (не угадывай).
- `blocks` — где тема видна яснее всего, не все подряд.
- Обычно 1–3 главные. Ни одна тема не подходит — `[]`: заметка «красивые кадры
  из сериала» про тайтл, а не про тему, её свяжет другой канал.
- `реальные-места` + `"place": "Коулун"` (место в именительном падеже).
- `по-мотивам` — только если пост **прямо говорит**, что вырос из нашего
  материала («гляньте новое эссе», «в новом выпуске „Бунко!“ мы обсудили»;
  «у нас есть бонус про это» — если с этого пост начинается или ради этого
  написан). + `"ref"`: `эссе`, `выпуск`, `бонус`, `Бунко`, `стрим`, `пост`;
  + `"quote"`: эти слова из текста.

**people.** Имя по-русски по Поливанову, «Имя Фамилия»; есть в списке
известных — пиши ровно так. Роль (в этом посте): мангака, режиссёр, аниматор,
арт-директор, дизайнер персонажей, композитор, сэйю, продюсер, сценарист, автор
ранобэ, автор игры, другое. `главный` — пост о человеке (в заголовке, текст
о его пути, стиле, работах); `упомянут` — назван как автор, участник, пример.
Новых добавляй смело. Персонажей и людей вне аниме и манги — нет, если пост
не о них.

**studios.** Как в карточках тайтлов (MAPPA, Science SARU, Studio Ghibli,
Kyoto Animation, Madhouse, Doga Kobo). `главная` — пост о студии;
`упомянута` — «анимацией занималась…». Нет в тексте — не добавляй.

**subjectAnime** — только когда счётчик ошибся: тайтл — предмет или повод
поста, а счётчик считает его мимоходным или не узнал («Знакомьтесь:
[арт-директор]», написанный ради сериала из первого абзаца; приём, разобранный
на сериале, названном один раз). Уже главный по счётчику — не пиши.

**coverage** — для каждого тайтла, главного по счётчику, и каждого из
subjectAnime. `общий` — о тайтле в целом (сериал, первый сезон как вход,
«стоит ли смотреть»). `узкий` — одна арка, сезон (не первый), фильм франшизы,
серия, персонаж, приём; в `aspect` — что именно. Главный по счётчику, но
на деле пример — охват всё равно ставь, а в фильтре скажи «пример».

**filter** — в этом блоке тайтл тема или пример? Решай по блоку.
- `тема` — о тайтле говорят: что в нём, чем хорош или плох, что с ним
  случилось. Всегда тема: раздел подборки о тайтле (даже короткий); тайтл
  в анонсе сезона с парой фраз о нём; тайтл, вокруг сравнения с которым
  построен пост («понравился X — вот Y»: X в заголовке или сравнение в начале
  и в конце); тайтл, которому дана оценка или место (премия, итоги, топ,
  анонс: «заслуживал награду больше», «слабейший в списке»); **в посте
  о человеке — его работа, если сказано, что он в ней сделал** («срежиссировал
  четвёртую серию X», «был арт-директором Y»).
- `пример` — тайтл нужен, чтобы сказать о другом, оценки нет: мимолётное
  сравнение, перечисление в ряду, шутка, «жду продолжения X» одной строкой,
  работа человека, названная только списком («работал над X, Y и Z»), имя
  человека или студии, совпавшее с названием.
- Сомневаешься — `тема`.

## Примеры (не из твоей пачки)

**Заметка «Реальные места Харухи!»** — «ради нового эссе» прямо указывает на
наш материал; о сериале самом ничего — охват узкий; блок о местах сериала —
тема.

```json
{ "id": "realnye-mesta", "about": "Фоторепортаж о поездке в Нисиномию — город, где происходит „Меланхолия Харухи Судзумии“",
  "labels": [{ "code": "реальные-места", "level": "главная", "blocks": [0, 4], "place": "Нисиномия" },
             { "code": "по-мотивам", "level": "главная", "blocks": [0], "ref": "эссе", "quote": "Ради нового эссе «Харухи Судзумии» мы съездили в город" }],
  "people": [], "studios": [], "subjectAnime": [],
  "coverage": [{ "anime": "suzumiya-haruhi-no-yuuutsu", "scope": "узкий", "aspect": "реальные места действия", "why": "пост о местах, а не о сериале" }],
  "filter": [{ "q": "Ф1", "verdict": "тема", "why": "блок о местах, где происходит „Харухи“" }] }
```

**Заметка «Как фанфики изменили аниме?»** — счётчик назвал главным Re:Zero
(один раз в перечислении) и мимоходным «Подручного Луизы», о котором весь
пост: «Луиза» — в subjectAnime, Re:Zero — «пример», охват у него всё равно
стоит.

```json
{ "id": "kak-fanfiki-izmenili-anime", "about": "Как волна фанфиков по „Подручному Луизы“ породила новую моду на исекаи",
  "labels": [{ "code": "исекай", "level": "главная", "blocks": [4] }, { "code": "фандом", "level": "главная", "blocks": [2, 3] }],
  "people": [], "studios": [],
  "subjectAnime": [{ "anime": "zero-no-tsukaima", "why": "весь пост — о фанфиках по „Подручному Луизы“, хотя назван он один раз" }],
  "coverage": [{ "anime": "zero-no-tsukaima", "scope": "узкий", "aspect": "роль в истории жанра", "why": "исток волны фанфиков" },
               { "anime": "re-zero-kara-hajimeru-isekai-seikatsu", "scope": "узкий", "aspect": "пример исекая новой волны", "why": "назван в перечислении" }],
  "filter": [{ "q": "Ф1", "verdict": "пример", "why": "Re:Zero назван в ряду тайтлов новой волны, о нём ничего" }] }
```
