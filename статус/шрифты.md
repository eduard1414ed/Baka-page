# Свои шрифты вместо Google Fonts — подробности

> Это подробности одной части работы. Сводка по всему проекту — в [СТАТУС.md](../СТАТУС.md),
> правила, выведенные из этого опыта, — в [CLAUDE.md](../CLAUDE.md).

## Что сделано — 9 августа 2026

Три гарнитуры скачаны, обрезаны и положены в `public/fonts/`. Сайт больше
не зависит от `fonts.googleapis.com`.

**Причина не в скорости, а в доступности.** Зарубежные сервисы в России
периодически становятся недоступны, и ставить показ текста в зависимость
ещё от одного чужого домена — лишний риск. Свои файлы отдаются с того же
`bakapodcast.com`, что и весь остальной сайт: не открылся сайт — не открылось
ничего, промежуточных состояний нет.

**Подключения в CSS пока нет.** Это осознанно: файлы лежат, но ни один
`@font-face` на них не ссылается. Подключение — часть перехода на светлую тему,
делается отдельно. Сейчас сайт рисуется теми же шрифтами, что и вчера
(`--font-heading: Georgia`, `--font-body: -apple-system…` в `src/styles/tokens.css`).

## Откуда взяты исходники

Адреса не набирались по памяти, а получены запросом к API самих хранилищ.

- **Literata** — `google/fonts`, папка `ofl/literata`, файлы
  `Literata[opsz,wght].ttf` и `Literata-Italic[opsz,wght].ttf`.
- **IBM Plex Mono** — `google/fonts`, папка `ofl/ibmplexmono`, файлы
  `IBMPlexMono-Regular.ttf` и `IBMPlexMono-SemiBold.ttf`.
- **Inter** — релиз `rsms/inter` **v4.1**, архив `Inter-4.1.zip` (33 МБ),
  внутри `InterVariable.ttf`.

**Файла `Inter.var.woff2` больше не существует** — это имя из версии 3.x.
В v4.1 переменный Inter называется `InterVariable`. Если понадобится обновить
шрифт, искать надо по новому имени.

Исходники (три с лишним мегабайта `.ttf` и архив на 33 МБ) в репозиторий
не клались и лежали во временной папке, которая удаляется вместе с сессией.

## Чем обрезано и как повторить

Утилита `pyftsubset` из пакета `fonttools`. Ставилась в изолированное
окружение во временной папке — в системный Python ничего не добавлено.
Если понадобится повторить:

```
python3 -m venv /tmp/шрифты/venv
/tmp/шрифты/venv/bin/pip install "fonttools[woff]"
/tmp/шрифты/venv/bin/pyftsubset ИСХОДНИК.ttf \
  --unicodes="U+0000-00FF,U+0400-045F,U+0490-0491,U+2116,U+2000-206F,U+2122,U+2190-2193,U+2197,U+2212,U+23F8,U+25B6,U+26A0,U+2715" \
  --flavor=woff2 --output-file=РЕЗУЛЬТАТ.woff2
```

Что оставлено: латиница с диакритикой, кириллица, ё/Ё, знак №, типографские
тире, кавычки и многоточие, ™, стрелки, минус и значки интерфейса.
Что выброшено: греческий, вьетнамский и всё прочее, чего на сайте не будет.

**Ключа `--variations=*` в `pyftsubset` не существует** — программа отвечает
`ERROR: Unknown option`. Он не нужен: `fonttools` сохраняет переменные оси сам.
Проверено по факту — после обрезки у Literata и Inter оси на месте
(см. таблицу выше), а не только по обещанию документации.

## Набор символов пришлось расширить

Исходный список символов не покрывал значков, которые сайт уже использует.
Проверка прошла по всем файлам в `src/components`, `src/pages`, `src/layouts`:
нашлись `→ ← ↗ ▶ ⏸ ✕ ⚠`, а в списке были только `↑` и `↓`. Добавлено
`U+2190-2193, U+2197, U+23F8, U+25B6, U+26A0, U+2715` — прибавка к весу
всех пяти файлов составила **988 байт**.

**Часть значков отсутствует в самих гарнитурах**, добавить их невозможно:

| Значок | Literata | Inter | Plex Mono |
|---|---|---|---|
| `← ↑ → ↓` | есть | есть | есть |
| `↗` | нет | есть | есть |
| `▶` | есть | есть | **нет** |
| `⚠` | нет | есть | **нет** |
| `⏸` `✕` | **нет** | **нет** | **нет** |

Практический вывод: `↗` у внешних ссылок и `▶` у плеера будут родными, если
шрифтом интерфейса станет Inter. **Пауза `⏸` и крестик `✕` всегда будут
рисоваться системным шрифтом** — они не нарисованы ни в одной из трёх гарнитур.
Чинится только заменой самих значков (например, на `||` и `×` из обычной
латиницы) — это решение по дизайну, а не по шрифтам.

Японские названия тайтлов (`波`, `風`, `ミナト`) и эмодзи в трёх старых постах
(`ep-43`, `ep-50`, `ep-53`, `ep-122`) тоже всегда будут системными: этих знаков
нет ни в одном текстовом шрифте латиницы. Это нормально и не чинится.

## Лицензия

Все три гарнитуры — **SIL Open Font License 1.1**: бесплатны, разрешают
коммерческое использование и изменение (в том числе обрезку), но требуют
распространять текст лицензии вместе со шрифтами. Раз файлы теперь раздаются
с нашего домена, это наша обязанность. Закрыто файлом `public/fonts/OFL.txt`:
три авторские строки, ссылки на первоисточники и полный текст лицензии,
взятый у `google/fonts`, а не написанный по памяти.

## Что проверено и чем

- **Обрезка не испортила шрифты** — все пять файлов открыты `fontTools`:
  формат `woff2`, переменные оси на месте, кириллица (`А`, `я`, `ё`), `№`,
  тире и ёлочки есть, греческого `α` и вьетнамского `ế` нет.
- **Файлы попали в сборку целыми** — `dist/fonts/` совпадает с `public/fonts/`
  побайтово (`cmp`), подпись файла `wOF2`.
- **Сервер их отдаёт** — локальный `npm run preview`, запрос через `curl`:
  код `200`, тип `font/woff2`, размер совпадает с файлом на диске. Проверены
  все пять, не один.
- **Сборка проходит** — три полных прогона `npm run build` без ошибок.

**Чего НЕ проверено:** как шрифты выглядят на экране. Проверить это сейчас
нельзя в принципе — они не подключены в CSS, ни одна страница их не запрашивает.
Смотреть будет что после перехода на светлую тему.

## Побочное наблюдение: число файлов в сборке гуляет

При одинаковом содержимом два прогона подряд дали 541 и 544 файла. Разница —
три превью-обложки выпусков `dist/episodes/*-og.jpg`: они делаются из обложек,
которые тянутся по сети, и в неудачной сборке сборка сама сообщила
«Сделал 2 jpeg-обложек» вместо обычных пяти. К шрифтам отношения не имеет,
это уже описанная в `СТАТУС.md` зависимость сборки от внешних данных.
Файлы `pagefind` при этом меняют имена (в них хэш), но не количество — их
стабильно 32.

Практический вывод: запас по лимиту Cloudflare считать по большей цифре,
а разброс в пару файлов между сборками поводом для тревоги не считать.
