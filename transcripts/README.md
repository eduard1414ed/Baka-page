# Рабочие файлы прогона расшифровок

Здесь остались только служебные файлы. **Сами расшифровки переехали
в `src/content/transcripts/`** — со схемой в `src/content.config.ts`,
сайт их читает и показывает на странице выпуска (тз/05, шаг 5).

## Что внутри

- `<guid>.corrections.json` — предложения исправить названия аниме.
  Есть не у всех: при прогоне архива сверка названий не запускается,
  её дают отдельно (`--recheck-names`). Сайт эти файлы не читает.
- `state.json` — что уже обработано, каким сервисом и почём.

Формат у обоих не такой, как у расшифровки, поэтому в
`src/content/transcripts/` их класть нельзя — сборка упадёт на схеме.

## Как обновлять после нового прогона

На сервере:
```
ssh -i ~/.ssh/hetzner_baki root@167.233.251.252
cd /root/baki-transcripts && python3 pipeline.py --export /root/transcripts.tar.gz
```
На своём компьютере — распаковать во временную папку и разложить по двум
местам: расшифровки к остальным, служебное сюда.
```
scp -i ~/.ssh/hetzner_baki root@167.233.251.252:/root/transcripts.tar.gz /tmp/
mkdir -p /tmp/tr && tar -xzf /tmp/transcripts.tar.gz -C /tmp/tr

# служебное — сюда
mv /tmp/tr/state.json /tmp/tr/*.corrections.json transcripts/
# расшифровки — в контент сайта
mv /tmp/tr/*.json src/content/transcripts/
```

Оригиналы живут на сервере в `/root/baki-transcripts/output/`, но держать их
в единственном экземпляре нельзя — за них заплачено. Вторая копия — git.

## Видеоэссе: текст из сценария, время из звука (тз/05, шаг 2)

У 34 выпусков «Эссе» и «Врата аниме» есть готовый сценарий, и текст на сайте
берётся из него, а не из распознавания. Распознавание там работает как
измерительный прибор: слова кривые, но у каждого свой таймкод.

Порядок — два шага, и разделены они намеренно.

**1. Распознать (платно, на сервере).** Голос один, поэтому разделение спикеров
и измерение высоты голоса выключены:
```
python3 pipeline.py --guid <guid> --force --single-speaker
```
`--force` нужен потому, что эти выпуски исключены из обычного прогона архива
(`EXCLUDE_TITLE_PARTS` в `pipeline.py`) — у них другой путь.

**2. Подставить сценарий (бесплатно, у себя).** Работает с уже скачанным
`*.words.json.gz`, в сеть не ходит:
```
python3 scripts/transcribe/align_essays.py --input <папка с output/>
```

**Почему два шага, а не один.** Второй ничего не стоит и его можно
перезапускать сколько угодно. Будь он внутри распознавания, любая правка правил
сопоставления означала бы повторную оплату всех 36 выпусков.

Пары «сценарий → выпуск» лежат в `scripts/transcribe/essay-map.json`,
подтверждены заказчиком 8 августа 2026. **Не пересопоставлять на лету:**
переименованный файл или поправленный заголовок поста молча увёл бы сценарий
к другому выпуску. Проверить, что карта не разошлась с папкой:
```
python3 scripts/transcribe/make_essay_map.py --check
```
